# Contributing

Contributions are accepted under **AGPL-3.0-only**.

By opening a pull request, you confirm that you have the right to submit the
code and agree that your contribution is licensed under AGPL-3.0-only. No CLA is
required. Because there is no CLA, the project cannot be relicensed under a
different license without permission from every contributor.

Please keep the SPDX headers on source files and update
`THIRD_PARTY_NOTICES.md` if you add or change a dependency.
